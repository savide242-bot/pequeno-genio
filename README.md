# Pequeno Génio — 30 Dias de Descoberta
## Página de Vendas de Elevada Conversão (Moçambique)

Esta página de vendas foi concebida por uma equipa multidisciplinar de copywriting de resposta directa, design infantil premium, optimização de taxa de conversão (CRO) e frontend ultra-rápido para telemóveis.

---

### 📁 Ficheiros do Projecto

- **`index.html`**: Estrutura semântica completa com todas as 13 secções estratégicas, mockups vetoriais em SVG, botões funcionais e links directos.
- **`styles.css`**: Design visual mobile-first, paleta oficial (Azul-marinho, Verde-água, Amarelo, Coral, Creme, Branco), tipografia amigável e refinada, cartões com sombras suaves e micro-interacções.
- **`script.js`**: UX interactiva para o acordeão de FAQ, rolagem suave para âncoras (`#planos`) e barra fixa inferior de conversão para telemóveis.

---

### 🚀 Como Visualizar e Testar Localmente

1. **Directamente no Navegador:**
   - Clica duas vezes no ficheiro `index.html` para abrir em qualquer navegador (Chrome, Edge, Safari, Firefox).
   - Não requer dependências, nem comandos `npm install`, nem configurações de backend.

2. **Com Servidor Local (Opcional):**
   - Se utilizares Python: `python -m http.server 3000`
   - Se utilizares a extensão *Live Server* do VS Code: clica em "Go Live".
